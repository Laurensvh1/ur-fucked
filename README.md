# Ur Fucked

Party games to decide who is fucked: who gets the drinks, takes a shot, picks someone up, or whatever you agree on. Decide what the loser has to do, pass one phone around, pick a game, and the loser is fucked.

## Games
- **Shortest Straw**: everyone picks a straw, the shortest one loses.
- **Hot Potato**: pass the phone until the bomb explodes.
- **Wheel of Doom**: spin a wheel with everyone's names.
- **Reaction Duel**: tap when the screen turns green. Slowest (or a false start) loses.
- **Doom Card**: take turns flipping cards until someone finds the doom card.

## Run locally
No build step, just plain HTML, CSS and JavaScript.

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173. On a phone, use "Add to Home Screen" to install it as an app.
